# LeetCode 75

[LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) 스터디 플랜을 하루 단위로 풀어나가며 기록한 저장소입니다.

각 문제는 `week{N}/day{M}` 폴더에 정리되어 있고, 폴더마다 그날 푼 문제의 풀이 코드와 회고(Velog 포스트 원고)가 함께 들어 있습니다.

## 폴더 구조

```
week{N}/day{M} - {주제}/
├── {문제번호}-{문제 제목}.py              # 처음 통과한 풀이
├── {문제번호}-{문제 제목}-improvement.py  # 더 나은 방식으로 다시 푼 개선 버전 (있는 경우)
└── day{M}_post.md                        # 그날의 회고 및 Velog 포스트 원고
```
